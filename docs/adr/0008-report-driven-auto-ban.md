# 檢舉驅動的自動封禁

用戶被檢舉達 tier 門檻時系統自動封禁，防止 spammer 利用檢舉訊號在操作員介入前就被攔截。採累計犯規升級模型（非滾動窗口重置），讓重犯者越封越重：

- 第 1 次觸發：tier 1，封禁 1 天，一般封鎖
- 第 2 次觸發：tier 2，封禁 1 週，一般封鎖
- 第 3 次觸發：tier 3，封禁 1 個月，一般封鎖
- 第 4 次觸發：永久封禁，完全封鎖

門檻由控制台設定（預設 5/10/20 次檢舉，24 小時滾動窗口計算）。tier 1-3 為一般封鎖（可看、不能留言），讓操作員有介入空間；永久封禁升級為完全封鎖。操作員可在控制台看到自動封禁狀態與原因（觸發 tier、檢舉數、犯規累計次數），可手動解封。審計紀錄記「系統自動封禁」有別於操作員手動封鎖。

不採滾動窗口重置模型：spammer 封禁期過後又從 tier 1 開始，等於沒有升級嚇阻力。
